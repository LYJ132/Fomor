# 任务：问题聚合

把一批用户问题聚合成少量「探索主题」。不要只按关键词相似度分组，要判断它们是否指向同一项工作、同一个目标或同一条解决路径。

## 输入

分析日期：{{date}}

事件列表：

{{events}}

## 判断要求

- 同一项目、同一会话不是充分条件；
- 表面关键词不同但目标一致，可以合并；
- 同一项目内完全无关的问题，不要强行合并；
- 无法判断时，宁可单独成组，并说明原因；
- 每组至少 1 条事件，最多不超过全部事件的 60%，除非确实只有一个主题。

## 输出 JSON

```json
{
  "topics": [
    {
      "name": "不超过 16 字的主题名",
      "summary": "一句话说明这些问题的共同点",
      "event_ids": ["evt_..."],
      "reason": "为什么把它们放在一起；如果证据弱，明确说明",
      "confidence": 0.0
    }
  ],
  "unmerged_event_ids": ["evt_..."]
}
```
